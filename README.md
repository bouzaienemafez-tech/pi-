# SCB Investor Gate

Public investor-facing dashboard for `SCB` (Les Ciments de Bizerte).

## Content

- `index.html`: standalone dashboard ready to open in any browser

## Purpose

This site summarizes:

- the financial deterioration of SCB
- the stock market trajectory of the company
- the predictive model outputs
- the investor recommendation and decision gate
